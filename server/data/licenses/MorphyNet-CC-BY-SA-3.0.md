MorphyNet derives morphology from Wiktionary contributors. WordLoop normalizes lemma/POS IDs, validates entries against OEWN, filters ordinary inflections and unsupported records, deduplicates pairs, and imports a vocabulary-scoped subset. Original line numbers, TSV fields, file revision/checksum, attribution and Wiktionary links remain in each imported relation's provenance.
