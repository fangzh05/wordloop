# Learning latency optimization — 2026-10-01 (Asia/Shanghai)

Based on `codex/exercise-balanced-learning-flow` at `5c43df1503b00216f399160d102ba2d05fe6a281`.

Semantic lesson and consolidation grading now request a compact verdict, task fulfillment, message, short hint, optional error excerpt, and reference on a second miss. Output budgets are 600 tokens normally and 900 on repair (previously 1200/1800). Short hints are mapped into the existing explanation field. Existing full responses remain readable. A correct verdict normalizes its error layer to none; an incorrect verdict with none uses an explicitly failed dimension when supplied, otherwise the existing broad meaning fallback. Invalid JSON or missing core feedback still permits one retry. A missing reference on the second miss is core feedback and still requires repair; the server cannot invent an answer. First-miss references are suppressed.

Analytics dimensions are no longer fabricated from a global verdict. Compact semantic responses leave unassessed skills as not_assessed through the existing evidence adapter. Deterministic fixed-answer exercises retain their assessed evidence. Detailed semantic skill coverage will be lower; this change does not introduce a background model pipeline or modify historical data. Algorithmic activity selection, accepted-answer routing, and FSRS scheduling remain intact.

New round plans are durably frozen once before generation, retaining IDs across failure/retry. Subsequent words with frozen plans no longer write a generation_error checkpoint before successful generation. They persist a retry cursor on failure and use revision-conditional persistence on success. Existing first-round freezing remains synchronous to preserve crash recovery; planning is not moved into pretest. Queue vocabulary is fetched once and reused by the planner, which retains a bounded history window. Standalone planner callers fetch vocabulary and history concurrently. Invalid exercise content still requires validation; answer leakage and activity type checks are retained.

`grading_ms` now stores the measured grading duration on lesson/consolidation submission. `active_ms` remains null because server wall time is not trustworthy foreground study time. With `WORDLOOP_PERF_LOG=1`, logs include vocabulary/planning/freezing/final persistence/submission database durations and each model attempt's response-header latency, total duration, output-token usage when supplied, retry reason, and finish reason. Response-header latency in this non-streaming client is not first-token latency. Logs omit prompts, answers, API keys, and repair text.

Validation: typecheck and full build passed. Full test run: 610 passed, 2 skipped, 1 failed. The failing capturedNotesMigration test expects migration filenames absent from the existing README; it was also reproduced at the unchanged base commit. Added tests cover compact feedback, no fabricated dimensions, first-miss reference suppression, frozen-plan single-write success, durable failure cursor, and concurrent-client changes during both successful and failed generation.

No production latency benchmark or deployment was performed. Token limits are output ceilings, not measured response time or actual token consumption; assess live improvements with the instrumentation before assigning latency percentages.
