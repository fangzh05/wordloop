一个模型，一层记忆。

ChatGPT 负责解释、出题与纠错。Wordloop 只处理结构化状态和交互式卡片。

01

导入

把扇贝词表粘贴进卡片。去重但保留原顺序，不覆盖过去的学习进度。

02

学习

ChatGPT 按 5–7 词推进预测试、发音和输出练习，不一次倾倒全部内容。

03

记住

每次作答更新错词层与复习时间；下一次对话从真实状态继续。

GPT Sites + MCP

可以接入，但职责要分开。

同一个 GPT Site 同时提供产品页面和标准 Streamable HTTP /mcp。ChatGPT 连接这个地址，Supabase service-role key 只存在 Sites 的服务端运行环境。

  1. 1
    初始化 Supabase

    在 SQL Editor 粘贴并运行 Wordloop setup.sql。

  2. 2
    配置 Sites 环境变量

    密钥只注入 Worker，不进入网页或 Widget。

  3. 3
    连接 ChatGPT

    在 Developer Mode 中添加本站的 /mcp 地址，然后开始学习。
